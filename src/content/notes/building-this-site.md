这个站用 Astro 构建。选它的原因很朴素：内容是 Markdown，输出是纯静态网页，快、稳、几乎零维护成本。

## 为什么不用动态 CMS

个人站的内容更新频率很低，为一月几篇文章维护一台服务器、一个数据库、一套后台，投入和产出完全不成比例。静态生成的思路是：**写作时编辑文件，构建时生成网页，部署时只上传 HTML**。

## 技术选型

| 关注点 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Astro | 内容驱动、默认零 JS、Markdown 原生支持 |
| 样式 | 手写 CSS | 没有模板味，每一像素都可控 |
| 部署 | GitHub Pages | 免费、push 自动构建 |

## 本地开发

```bash
npm install
npm run dev    # 本地预览
npm run build  # 生成 dist/
```

开发体验上最舒服的一点是热更新：改 Markdown 文件，浏览器里立刻能看到效果，写作和排版之间没有打断。
